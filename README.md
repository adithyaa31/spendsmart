# SpendSmart

A responsive personal-finance design thinking prototype. The starter transactions are synthetic. Transactions, budgets, and goals are saved in this browser.

## Run locally

Requires Python 3.10 or newer. No packages are needed.

```powershell
py server.py
```

Open <http://127.0.0.1:8001>. Stop the server with `Ctrl+C`. Use this Python server (not `py -m http.server`) so the ML endpoints and AI proxy work.

## Enable Money Doctor (optional)

Money Doctor uses OpenAI’s Responses API. Create a local `.env` file by copying `.env.example`, then add your API key to `OPENAI_API_KEY`. Restart the server afterward. The `.env` file is ignored by Git; never commit or share it. You need an OpenAI API key with API access.

Before the first question in each browser tab session, the app asks for consent to send the question, recent chat history, recent transaction dates, merchants, categories and amounts, budgets, and goals to OpenAI. Transaction notes and API keys are not sent. The key stays on the local server. If no key is configured, Money Doctor shows a setup message and does not produce a simulated answer.

## What works

- Dashboard totals, spending charts, transaction editing, search, filters, and CSV export
- Editable budgets and savings goals
- Transparent rule-based spending observations
- A Multinomial Naive Bayes category suggester trained from the descriptions and categories of labeled expenses stored in this browser; suggestions require user confirmation
- An Isolation Forest anomaly model fit from expense amounts and category-relative amounts; review prompts are not fraud detection
- Money Doctor answers generated by OpenAI and grounded with recent transaction data after consent
- Interactive purchase scenarios and a clearly labeled straight-line baseline projection
- Mobile layout and local data reset/deletion

The ML models train from the current saved transaction history and report when there is too little data. Demo records are synthetic and may be used as training examples until removed. No transaction database or login is included; each browser has its own local data. The app is an educational prototype, not a financial adviser.
